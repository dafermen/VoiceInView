# Roadmap
0. Foundation — implemented, Mac build/test gate pending.
1. Microphone — implemented with volume meter, lifecycle safety and tests; Mac/device validation pending.
2. Offline speech — English model readiness, Apple analyzer, partial/final assembly, duplicate prevention, Airplane Mode proof and latency observations.
3. Captions — readable typography, scrolling, appearance, screen wake, elapsed time, accessibility; pause/resume only if reliable.
4. Sessions — local persistence, history, rename/delete and search if practical.
5. Export — text, copy and native sharing; evaluate PDF separately.
6. Readiness/settings — permission, assets/storage readiness and guided offline test.
7. Reliability — 30/60/120 minute profiling, battery/thermal and interruptions/routes.
8. Privacy/security review — actual data flows, manifests and policy.
9. App Store readiness — release build, accessibility, metadata, icon and compliance.
10. Optional online AI — only by explicit request, separate backend and informed user action.

Stop after each phase. User authorized Phase 1 before Phase 0 Apple validation. Both acceptance gates remain pending until build/test/device evidence is recorded.
